Config SO Builder
Thử FROM.xmlKiểm tra .soCách dùng

FROM.xml vào, libconfig.so ra.

Một builder gọn cho Termux/Android: đọc FROM.xml, kiểm tra cấu hình, biên dịch mã C/C++ trong Source/ bằng clang++ rồi link thành thư viện native thật.

Tải builder (.zip) Thử sửa FROM.xml ngay 
pkg install clang
bash build.sh
  1. FROM.xmlkhung cấu hình: module, giá trị, export
  2. Kiểm trađang chờ
  3. Đọc Source/*.c, *.cc, *.cpp
  4. Biên dịchclang++ -fPIC -std=c++17
  5. Link-shared
  6. output/libconfig.sofile ELF thật, kiểm tra symbol export

Sửa FROM.xml, xem kết quả ngay

Trình duyệt chạy cùng các luật kiểm tra như build.sh. Kéo thanh trượt để xem bộ lọc đầu vào phản ứng thế nào với sensitivity, smooth, maxSpeed và deadZone. Bước biên dịch và link chỉ chạy trên máy của bạn.

Kết quả

    
        
    Tệp Source/ được khai báo trong Modules có tồn tại hay không sẽ được build.sh kiểm tra khi chạy thật.
    
      
    
    
    
  
    

    


    
  
    .so là ELF thật, không phải đổi đuôi
    
  
    Đổi tên libconfig.xml thành libconfig.so không tạo ra thư viện. Hệ điều hành đọc vài byte đầu để biết đó có phải ELF không. Thử với file của bạn, trình duyệt chỉ đọc 64 byte đầu và không tải file lên đâu cả.
    
  
    
    
    
      
    
        
    FROM.xml (văn bản)
    
        3C 3F 78 6D 6C 20 76 65 72 73 69 6F 6E …
    
        chuỗi ký tự <?xml version …
      
    
      
    
        
    libconfig.so (ELF)
    
        7F 45 4C 46 02 01 01 00 … 03 00 B7 00
    
        7F "ELF", 64-bit, little-endian, ET_DYN, aarch64
      
    
    
    
    
    
      
      
    
    
    
  
    

    


    
  
    Chạy trên Termux
    
  
    Build cho ra .so cùng kiến trúc với máy đang build. Trên điện thoại arm64, đó là aarch64.
    
  
      
    
    1. Cài clang, một lần
      pkg update && pkg install clang
      2. 
    
    2. Giải nén và vào thư mục
      unzip Config_SO_Builder.zip
cd Config_SO_Builder
      3. 
    
    3. Build, rồi chạy test nếu muốn
      bash build.sh
bash build.sh test
      Kết quả nằm ở output/libconfig.so. Lỗi được gắn nhãn ENV, FROM, SOURCE, COMPILE, LINK hoặc VERIFY.
      4.
